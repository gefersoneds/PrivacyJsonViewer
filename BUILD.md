# Build instructions (for AMO reviewers) — JSON Path Viewer

This document describes how to reproduce the exact `content.js` and other files
contained in the submitted add-on package.

## Source files

The extension source lives in `src/`:

- `content.ts` — entry point (content script)
- `path.ts` — path parser and matcher
- `viewer.ts` — JSON tree renderer
- `search.ts` — search controller
- `copy.ts` — copy handler
- `viewer.css` — styles (copied as-is, not processed)
- `manifest.base.json` — base manifest (the Firefox manifest is generated from it)
- `icons/` — PNG icons

Build tooling:

- `vite.config.ts` — Vite configuration. Bundles the TypeScript entry
  (`src/content.ts`) with its imports into a single `content.js`, and generates
  the per-browser `manifest.json`.
- `scripts/gen-icons.mjs` — regenerates the PNG icons (optional; icons are
  already committed under `src/icons/`).
- `scripts/package.mjs` — zips `dist/<target>/` into `release/`.

## System requirements / build environment

- Operating system: any (Windows, macOS, or Linux). It was built on Windows.
- Node.js: v24.14.1 (any Node.js >= 18 should work).
- npm: v11.11.0 (bundled with Node.js).
- No global tools required. All build dependencies (Vite, TypeScript) are
  declared in `package.json` and installed locally via `npm install`.

## Step-by-step build

From the project root:

```
npm install
npm run build:firefox
```

The Firefox build output is written to `dist/firefox/`. Its contents are exactly
what the submitted `.zip` contains:

- `content.js` (bundled + minified by Vite/esbuild)
- `viewer.css`
- `manifest.json` (generated by `vite.config.ts` for the Firefox target)
- `icons/icon48.png`, `icons/icon128.png`

To reproduce the exact `.zip` that was uploaded, run instead:

```
npm install
npm run package
```

This builds both the Chrome and Firefox targets and writes the zip files to
`release/` (e.g. `release/json-path-viewer-firefox-v1.0.0.zip`). The zip is
assembled by `scripts/package.mjs` using only Node.js built-ins.

## Notes

- The single build script that performs all steps is `npm run package`
  (defined in `package.json`), which runs the Vite builds and then the
  packaging script.
- Type checking (optional): `npm run typecheck`.
- The only transformation applied to source is TypeScript compilation +
  bundling + minification by Vite. `viewer.css`, `manifest.base.json`, and the
  icons are copied without modification.
- The extension does not collect or transmit any user data. The only stored
  state is the theme preference in `localStorage`.
- Dependency versions are pinned exactly in `package.json` and locked in
  `package-lock.json` for reproducible builds.
- `npm audit` may report advisories in `esbuild`/`vite`. These affect only the
  Vite dev server (`vite dev`), which is NOT used here. Production builds use
  `vite build`, so the shipped extension is unaffected.
